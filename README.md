# Generador de firmas para Gmail

Abrí index.html para editar y previsualizar tu firma. Los datos se guardan en el navegador.

## Publicación en GitHub Pages

1. Subí el contenido de este ZIP a la raíz de un repositorio.
2. En Settings → Pages, elegí Deploy from a branch y seleccioná main y /(root).
3. Una vez publicado, abrí el sitio HTTPS y usá Copiar firma. El avatar incluido se carga desde avatar-marco.gif en ese mismo sitio.
4. Pegá la firma en Gmail → Configuración → Ver toda la configuración → General → Firma. Guardá y envíate un mensaje de prueba.

Para añadir una imagen, subila al repositorio (por ejemplo a la carpeta imagenes), copiá su URL de GitHub Pages y pegala en URL pública del avatar. El selector de archivo solo previsualiza imágenes locales. Los archivos publicados en el sitio son accesibles públicamente.
